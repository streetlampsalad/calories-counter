# Specs

New specs, written with [spec-kit](https://github.com/github/spec-kit) by `/deliver` (see [`docs/agents/workflow.md`](../docs/agents/workflow.md)). Each folder is named after its Spec issue, `specs/<issue number>-<short-name>/`, and holds `spec.md`, `plan.md` and `tasks.md`. The templates are `.specify/templates/overrides/`.

Specs 001–019 are in [`docs/specs/`](../docs/specs/README.md) in the earlier format.
