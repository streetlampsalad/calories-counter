# Spike

Answer the Spike's question within its time box. Production code stays out; throwaway scripts live in the session's scratch space, never in the repo.

1. Restate the question and the decision it unblocks.
2. Find the answer from primary sources (official docs, the code, a real call where the Spike allows it). Record what you checked and when.
3. Write the findings where the Spike's `### Where the answer goes` says: each finding, its source, and its effect on the decision. Answer every open question the target spec or doc lists, or say why it stays open.

Done when every question has an answer or a stated reason it cannot be answered yet. Hand over ([SKILL.md](SKILL.md) step 4) with a docs-only pull request. A Spike that needs a secret, a real external account or a dashboard step needs Human review before you start: comment, flag it, and stop.
